## 🛠️ Installation

The CLI is already integrated into the project. Simply run:

```bash
# Interactive mode (requires user input)
npm run orchids
```

## 📖 Usage

### Interactive Mode
```bash
npm run orchids
```

This launches the full interactive CLI where you can:
1. Choose your preferred interaction mode
2. Describe your database needs
3. Review and approve execution plans
4. Watch real-time progress
5. Celebrate successful completion
